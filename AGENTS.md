# AGENTS.md

## ui-sdk

`@ui-sdk/react` and `@ui-sdk/core` are installed in `packages/rockin`.

Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read `packages/rockin/node_modules/@ui-sdk/react/docs/llms.txt`.

To build a new component, also search `packages/rockin/node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next to it.
