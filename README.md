# Rockstar UI

[![npm version](https://img.shields.io/npm/v/rockin)](https://www.npmjs.com/package/rockin)

Shared React UI components for Rockstar projects.

Install from npm:

```bash
bun add rockin
```

See the [package documentation](packages/rockin/README.md) for usage and development instructions.

## Documentation site

The docs live in `apps/docs` — a static-exporting Next.js app powered by
[Fumadocs](https://fumadocs.dev), rendering the components from `packages/rockin`
live with real demo data.

```bash
# dev server (builds the ui package first, then starts next dev)
bun run dev

# production build: ui -> docs -> ./out (static, deploy-ready)
bun run build

# regenerate API tables from source types
bun run --cwd apps/docs props

# regenerate the preview code snippets shown in docs
bun run --cwd apps/docs previews
```

### How the docs are wired

- **Component pages** (`apps/docs/content/docs/components/**`) are generated by
  `apps/docs/scripts/generate-component-docs.ts` — edit the config there, then run
  `bun run --cwd apps/docs build` (or the script directly) to regenerate the MDX.
- **Props tables** are extracted from the TypeScript source by
  `scripts/generate-props.ts` into `lib/props.generated.json` — hand-written rows
  are also supported via `<PropsTable props={[...]} />`.
- **Live previews** are plain React demos in `apps/docs/components/previews/*`,
  registered in `components/previews/index.tsx`; their source code is extracted
  into the Code tabs by `scripts/generate-preview-code.ts`.
- **Copy Page / AI** — every docs page exposes raw markdown at `/api/mdx/<slug>`
  (the "Copy Markdown" button and the View options popover).
- **Search** is fully static: the prebuilt index is served from `/api/search`
  and queried in the browser.
